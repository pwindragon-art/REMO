Technical Documentation

REMO 웹 서비스 개발 및 운영 안내서

공식 웹사이트, 랜딩페이지, 카드뉴스 생성기 시스템 명세서

버전: 1.0

배포 환경: Vercel / GitHub

1. 시스템 아키텍처 개요

별도의 유료 백엔드 서버 없이 정적 호스팅(Vercel)과 서버리스 클라우드(Google Apps Script)를 결합하여 운영비용 없이 자동화된 데이터 수집 및 콘텐츠 제작 도구를 제공하도록 설계되었습니다.

[Client Web Browser]
  ├─ index.html (메인 공식 홈페이지)
  ├─ landing.html ──(HTTP POST / no-cors)──> [Google Apps Script] ──> [Google Sheets DB]
  └─ cardnews.html ──(HTML5 Canvas Engine)──> 로컬 다운로드 (PNG / ZIP)

2. 프로젝트 디렉터리 및 모듈 명세

파일명 주요 기능 및 역할 종속 라이브러리
index.html 공식 웹사이트 메인 화면, 팀소개, 프로젝트 섹션, 네비게이션 링크 연동 Tailwind CSS
landing.html 리드 획득용 상담 접수 폼, 스프레드시트 비동기 데이터 전송 스크립트 탑재 Tailwind CSS
cardnews.html 1080x1080 정방형 카드뉴스 생성 엔진, 템플릿 제어, 개별 PNG 및 전체 ZIP 압축 다운로드 Tailwind CSS, JSZip

3. 핵심 연동 및 통신 규격

3.1 구글 스프레드시트 리드 연동 (Google Apps Script)

  • 엔드포인트 형태: Google Apps Script Web App (/exec 주소)
  • 보안 및 권한: 액세스 권한은 반드시 모든 사용자(Anyone)로 배포되어야 외부 폼 전송 가능
  • 전송 파라미터 규격: name, company, email, phone, message
  • CORS 처리: 브라우저 통신 시 mode: 'no-cors' 적용을 통해 요청 차단 방지

3.2 카드뉴스 생성 엔진

  • 캔버스 규격: 표준 인스타그램 및 소셜미디어 포맷인 1080px × 1080px 고정 해상도 렌더링
  • 데이터 구조: 단일 페이지 상태 객체 배열(slides[])을 통해 멀티 슬라이드 동적 관리
  • 압축 내보내기: JSZip 라이브러리를 통해 오프스크린 캔버스 Base64 데이터를 메모리상에서 압축 후 즉각 다운로드 링크 트리거

4. 배포 파이프라인 및 유지보수 가이드

  1. 코드 수정 및 반영: GitHub main 브랜치에 코드를 커밋하면, Vercel이 수 초 내에 감지하여 자동 빌드/배포를 완료합니다.
  2. 캐시 갱신: 배포 후 화면 변경이 안 보일 경우 브라우저 강력 새로고침(Ctrl + Shift + R 또는 Cmd + Shift + R)을 수행합니다.
  3. Apps Script 로직 갱신 주의사항: 구글 스크립트 코드 수정 시에는 스크립트 편집기에서 [배포] → [배포 관리] → 버전 '신규'로 갱신 배포해야 수정된 로직이 실제 시트에 반영됩니다.
